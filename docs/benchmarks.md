# Benchmarks (Phase 4 / FL-012)

**Status: not yet measured.** No performance level is promised; 30 FPS is a goal.

## Protocol

1. Connect power; record power mode, displays and background apps.
2. Same game build, save, camera position, resolution and simulation speed every run.
3. Warm shader caches separately; label runs cold or warm.
4. Test a new settlement and at least one developed settlement; record population.
5. Same route or view for 3–5 minutes, three runs per configuration.
6. Measure frame time with a supported tool. If only FPS is available, do not invent percentiles.
7. Record memory pressure and swap growth (Activity Monitor → Memory), thermals, artifacts, crashes.
8. Change one variable at a time; restore the baseline between experiments.

Start at 1920×1080, medium settings, as an experiment.
